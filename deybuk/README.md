# Фонд Сагасидейбук — сайт и приложение (PWA)

Адрес после публикации: `https://<ваш-домен>/deybuk/`

Сейчас работает на **демо-данных** — все суммы, имена и даты выдуманы.

## Файлы
- `index.html` — страница
- `app.css` — оформление
- `app.js` — логика: главная, сборы, пожертвование, отчёты, объявления, о фонде
- `data.js` — **демо-данные**. Чтобы поменять сборы, отчёты, ящики или объявления, правьте этот файл. Позже заменим его загрузкой с сервера.
- `manifest.webmanifest`, `sw.js`, `icons/` — чтобы сайт можно было установить на телефон как приложение и открывать без интернета

## Что ещё не сделано
- Оплата (СБП / карта) — кнопка «Оплатить» пока показывает демо-подтверждение
- Хранение данных и админка для фонда
- Фото

## Фото
В папке `img/` — временные фото со свободными лицензиями (авторы перечислены в `data.js` → `credits` и внизу страницы «О фонде»). Замените их своими фотографиями мечети, медресе и селения с теми же именами файлов.
