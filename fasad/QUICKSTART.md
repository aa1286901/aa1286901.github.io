# 🚀 Запуск Fasad AI (без MySQL!)

## Всё готово к запуску

База данных хранится в файле `data/db.php` (создаётся сам при первом запуске из `data/seed.json`) — никаких MySQL, никаких паролей!

## Что внутри

- ✅ 1 демо-пользователь: `magomed@fasad.ai` / `demo123`
- ✅ 3 демо-проекта с материалами и карнизами
- ✅ 15 материалов в каталоге
- ✅ 8 карнизов

## Запуск

1. **Загрузите файлы** на хостинг (все файлы в корень папки сайта)
2. **Откройте** `https://ваш-домен.ru/index.html`
3. **Готово!**

## Тестирование

### Вход в аккаунт:
- Email: `magomed@fasad.ai`
- Пароль: `demo123`

### Или попробуйте без регистрации:
- Нажмите "Попробовать без регистрации" на экране входа

## Проверка истории проектов

1. Зайдите в аккаунт
2. Перейдите в "Проекты"
3. Должны появиться 3 демо-проекта

## Проверка каталога

1. Перейдите в "Каталог"
2. Должны появиться 15 материалов
3. Работает поиск и фильтры

## Проверка профиля

1. Перейдите в "Профиль"
2. Должна загрузиться страница со статистикой
3. Работают все разделы меню

## Навигация

Все 4 вкладки нижнего меню работают:
- 🏠 Главная
- 📁 Проекты
- 📦 Каталог
- 👤 Профиль

## Создание нового проекта

1. Нажмите "Создать проект" на главной
2. Загрузите фото (или используйте демо)
3. Выберите материалы
4. Нажмите "Сгенерировать"
5. Получите результат!

## Обновление базы данных

Все изменения сохраняются в `data/db.php`:
- Пользователи
- Проекты
- Избранное

Файл автоматически обновляется при каждом действии.

## Совместимость

- ✅ PHP 7.4+
- ✅ Любой shared hosting
- ✅ Без MySQL
- ✅ Без Node.js
- ✅ Без Composer

## Структура

```
fasad/
├── index.html              # Приложение
├── api/                    # PHP API (все на JSON)
│   ├── config.php          # Конфигурация (без MySQL!)
│   ├── auth/               # Регистрация, вход
│   ├── projects/           # CRUD проектов
│   ├── upload/             # Загрузка фото
│   ├── generation/         # Генерация
│   └── user/favorites/     # Избранное
├── data/                   # Данные
│   ├── db.php              # ✅ База данных (JSON, создаётся сама)
│   ├── seed.json           # Демо-данные для первого запуска
│   ├── materials.json      # Материалы
│   └── cornices.json       # Карнизы
├── assets/                 # Изображения
├── css/                    # Стили
├── js/                     # JavaScript
└── uploads/                # Загруженные файлы
```
